# ページの型ごとの構成

どれもテンプレ（`templates/*.html`）に骨組みが入っている。ここは「なぜこの順か」と差し替えの注意。

---

## レポート型 — `templates/report.html`

**読む人**: 上司・取引先・会議の参加者。最初の画面で結論が欲しい。

```
表紙  … 上に黄色 8px の帯 → ブランド行（小さい四角＋名前）→ h1（900）→ サブ → メタ（期間・件数・作成日）
数字4枚 … 上罫 4px のカード。一番見てほしい1枚だけマゼンタ（.kpi.hot）
目次  … sticky。横スクロール可。リンク高さ 44px
章 ×n … 英字ラベル＋h2（左罫 6px シアン）→ リード1行 → 図 → 読み取り（.insight）→ 表
結論章 … 2列のカード。最重要の1枚だけインク地反転（.finding.key）
打ち手 … 「今すぐ / 今週 / 来月」の色付きラベル＋行動1行＋補足
フッター … 出典・集計条件・作成日・作成者
```

- 章は 5〜8 個まで。多いなら付録に回す
- 一覧（要対応リスト等）は aria-pressed のフィルタ＋件数＋状態チップ
- 印刷される前提なら `@media print` で目次を消し、章の途中で改ページしない（`break-inside:avoid`）

## デモ型 — `templates/demo.html`

**読む人**: 営業先・社内の決裁者。実物を触る前に流れを理解したい。

```
DEMO帯  … sticky。インク地＋黄色の「DEMO」タグ＋「表示はすべて架空です」＋右に「吹き出しを隠す」「最初から」
ステップ … 番号付きのタブ（aria-current="step"、下に 3px のシアン）
本体    … 左=実際の画面（白い枠の中にアプリの見た目）、右=黄色の吹き出し（300px、三角の矢印つき）
          900px 未満では吹き出しを画面の下に積み、矢印を上向きに
画面ごと … 入力 → 処理中（進捗バー＋チェックリスト）→ 結果（判定・3タイル・問題の行）→ 次の行動（CTA 2枚）
最後    … 前へ / 次へ
```

- 吹き出しには「なぜこうなっているか」「去年との違い」を書く（画面の説明の繰り返しにしない）
- 吹き出しの先頭に小さな黒地タグ（`解説` `ここが新しい`）
- 押せるボタンは全部動かす（次の画面へ進む・alert で反応する）。リンク切れのボタンを置かない

## ダッシュボード型 — `templates/dashboard.html`

**読む人**: 社内の担当者・管理職。毎日開く。異常にすぐ気づきたい。

```
ヘッダー … タイトル＋「最終更新 ○分前（最も古いデータ源）」＋再読み込み
KPI     … 4〜6枚。上罫 3px を状態の色で。押すとその一覧へスクロール（ボタンとして実装）
要対応  … 左に 4px の色バー＋レベルバッジ＋相手＋時刻＋本文2行（line-clamp）
担当別  … 表（名前・レベル・件数・推移スパークライン）。行を押すと右からドロワー
推移    … SVG スパークライン or 棒
```

- 背景はやや青みのある明るいグレー（`#eef2f8`）、パネルは白、角丸 12〜16px・影はごく薄く（社内画面だけの例外）
- レベルは文字バッジ（最優先/高/中/確認/参考）。色だけにしない
- 「0件」も状態として表示する（空欄にしない）。取得失敗は赤で明示

## LP型 — `templates/lp.html`

**読む人**: 見込み客。比較検討中で、料金と自分に合うかを知りたい。

```
ヘッダー … ロゴ／ナビ／右上に「はじめてのお客様」（#f95a4c）「ログイン」（#2864f0）
ヒーロー … ブランド3色の面を3分割。それぞれ「サービス名・料金（大きい数字）・一言・ボタン」
実績    … 数字＋「○年○月現在」
サービス … 色面ヘッダーのカード（シアン=手続き代行/イエロー=給与計算/マゼンタ=顧問）、本文は白
流れ    … STEP 番号＋見出し
FAQ     … Q/A を左に固定
CTA     … 主ボタン1つ
```

- 色面の上の文字: シアン・イエローの上は黒インク、マゼンタの上は白
- 写真を使うなら人物の切り抜きを色面の上に。背景写真を全面に敷かない
- 料金は「税込」「〜」を小さく添える。数字だけを大きく

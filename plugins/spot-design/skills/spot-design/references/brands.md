# ブランドと色

1ページに1ブランド。依頼にブランドの指定が無く、スポット社労士くん関連なら `spot`、社内ツールなら `internal`、
どれにも当たらなければ `neutral` を使う。

## spot — スポット社労士くん（既定）

| トークン | ライト | ダーク | 意味 |
|---|---|---|---|
| `--bg` | `#F3F6F7` | `#0D1317` | ページ背景（レポートは `#FFFFFF`） |
| `--surface` | `#FFFFFF` | `#162027` | カード・パネル（レポートは `#F5F7F8`） |
| `--tint` | `#E5F9FC` | `#10313A` | 淡いシアンの面（読み取り・強調行） |
| `--ink` | `#101820` | `#E7EDF1` | 文字・主ボタン |
| `--ink-2` | `#5B6773` | `#9AA8B3` | 補足の文字 |
| `--line` | `#D6DDE1` | `#2A3742` | 罫線 |
| `--cyan` | `#00C8E4` | `#29D3EA` | 手続き代行／通常・情報 |
| `--cyan-ink` | `#007A8F` | `#4FD8EC` | シアン系の**文字**（白地で 4.5:1 を満たす濃さ） |
| `--yellow` | `#FFD400` | `#FFD400` | 給与計算／今・デモ・解説 |
| `--magenta` | `#E5006E` | `#FF5AA6` | 顧問／料金・要対応 |
| `--magenta-ink` | `#C7005F` | `#FF5AA5` | マゼンタ系の文字 |
| `--ok` / `--ok-tint` | `#1B7F3B` / `#E8F5EC` | `#5CCB82` / `#14301F` | 問題なし |
| `--warn` / `--warn-tint` | `#9A5B00` / `#FFF4DE` | `#F2B44C` / `#3A2C12` | 要確認 |
| `--danger` / `--danger-tint` | `#C62828` / `#FDECEC` | `#FF7B7B` / `#3A1A1C` | 問題あり |
| `--r` | `4px` | | 角丸（小物は 2px、pill は 999px） |

- シアン・イエローの**面**の上の文字は `#101820`。白文字を置かない（コントラスト不足）
- シアンを**文字色**にするときは `--cyan-ink`（素のシアンは白地で 1.9:1 しかない）
- ヘッダーのボタン: はじめてのお客様 `#D4372A` / ログイン `#2864F0`（どちらも白文字）
  - 本番サイトの `#F95A4C` は白文字で 3.18:1 しかなく基準（4.5:1）に届かない。新しく作る画面は `#D4372A`（4.79:1）を使う
- マゼンタを**文字色**にするときは `--magenta-ink`（`#E5006E` は薄いグレー面の上で 4.29:1 しかない）。白文字を載せる**塗り**はダークでも `#E5006E` のまま（明るくしない）
- グラデーション禁止・影なし

## internal — 社内ダッシュボード

明るいスレート。目に優しく長時間見る前提。

`--bg #EEF2F8` / `--panel #FFFFFF` / `--panel2 #F4F6FB` / `--line #DDE3EE` / `--ink #16213A` / `--ink-2 #4A5672`
状態: `--red #D6293E` / `--amber #9A5B00` / `--teal #0B7A6D` / `--blue #2F6FDB` / `--violet #7048C8`（amber・teal は 12px の文字にも使うので、白地 4.5:1 を満たす濃さにしてある）
補足の文字 `--faint #5D6883`

レベルバッジ（文字色 / 背景 / 枠）:

| レベル | 文字 | 背景 | 枠 |
|---|---|---|---|
| 最優先 | `#FFFFFF` | `#D6293E` | `#D6293E` |
| 高 | `#B4182C` | `#FDECEE` | `#F3B4BC` |
| 中 | `#8F5200` | `#FFF4E0` | `#F2CF8F` |
| 確認 | `#2556B0` | `#EAF1FF` | `#B9CFF5` |
| 参考 | `#55607A` | `#F2F4F8` | `#D8DDE8` |

角丸 12〜16px、影は `0 1px 2px rgba(22,33,58,.05)` まで。比較用の系列色: `#D6293E #E08A00 #0F8F80 #2F6FDB #7048C8 #C2367F`

## neutral — どのブランドにも当たらないとき

spot の構造（フラット・角丸4px・罫で区切る）のまま、アクセントを1色にする。
`--accent` を1つ決め（既定 `#2864F0`）、強調はマゼンタの代わりに `--accent`、注釈の黄色はそのまま使ってよい。

## 他社ブランドの案件

案件の指定色 > このスキルの構造（余白・文字の段・罫で区切る・状態の3点表示）。色だけ差し替え、構造は変えない。

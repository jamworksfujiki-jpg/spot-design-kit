# spot-design — 画面を「第一稿から」この品質で出すためのスキル

このスキルが読まれたら、指示に「デザインを整えて」と書いていなくても、以下を**最初の版から**満たすこと。
素のHTML・AIっぽい装飾の第一稿を出して、指摘されてから直すのは不合格。

## 手順（この順で必ずやる）

1. **ページの型を決める**（下の表）。迷ったら依頼者に聞かず、内容から決めて最初の報告で「〇〇型で組みました」と書く
2. **テンプレをコピーして中身を差し替える**。ゼロから書かない。`templates/` の4つは、実際に評価の高かった画面から作った骨組み
3. **references/ を必要な分だけ読む**
   - 必ず読む: `references/principles.md`（なぜこう見えるのか・14原則・AIっぽさの排除）
   - 型ごとの構成: `references/page-types.md`
   - 色・ブランド: `references/brands.md`
   - 部品のクラス早見: `references/components.md`
4. **機械検査を通す**: `node <このスキルのフォルダ>/scripts/check-design.mjs <URL または HTMLパス>`
   - FAIL が 1 つでもあれば直す。FAIL が残ったまま「できました」と言わない
   - 出たスクショ（PC 1280px / スマホ 390px、ライト/ダーク）を**自分で画像として開いて見る**
5. **報告**: 型・使ったテンプレ・検査結果（PASS/WARN/FAIL の数）・目で見て直した点・未確認の点を書く

## ページの型

| 型 | こういう依頼 | テンプレ | 元になった実画面 |
|---|---|---|---|
| レポート | 分析・アンケート結果・月次報告・上司に見せる資料 | `templates/report.html` | 給与参謀セミナー アンケート分析 |
| デモ | 操作説明・画面の流れを見せる・営業用の疑似体験 | `templates/demo.html` | 年末調整チェック デモ |
| ダッシュボード | 社内の監視・一覧・担当者別・リアルタイム表示 | `templates/dashboard.html` | cs-monitor 危険度モニター |
| LP | サービス紹介・申込への誘導・料金を見せる | `templates/lp.html` | spot-s.or.jp トップ |

複数の型にまたがるときは主目的で1つ選ぶ。1ページに2つのブランドを混ぜない。

## 非交渉（どの型でも）

- **結論が最初**。ページの最初の画面で「何が言いたいか」と主要な数字が見える
- **色は意味で固定**（brands.md）。同じ色を別の意味で使わない。状態は色＋文字＋形で示す（色だけにしない）
- **余白は 4 の倍数**（4/8/12/16/20/24/32/40/48/56/64）。タップできる物は高さ 44px 以上
- **数字は `font-variant-numeric: tabular-nums`**、表の数字は右寄せ、単位は数字より小さく
- **ダークモードを最初から**: トークンを `:root` に置き、`@media (prefers-color-scheme: dark)` の `:root:not([data-theme="light"])` と `:root[data-theme="dark"]` の両方で上書き。`body` に背景色を明示
- **スマホ幅で横スクロールを出さない**: グリッドは `minmax(0,1fr)`、子に `min-width:0`、表は `overflow-x:auto` の箱に入れる
- **1ファイル1 `<style>`**。同じセレクタを2回定義しない
- **`:focus-visible` に 3px のアウトライン**、`prefers-reduced-motion` で動きを止める
- **データには出典と取得日**。取れていないデータを最新のように見せない。「最終更新」は複数ソースなら一番古い時刻を書く
- **デモ・見本は架空と明示**（上部に DEMO 帯）。実在の会社名・個人名を見本データに使わない

## やってはいけない（AIが作った感が出る原因）

グラデーション背景／絵文字アイコン／紫系のアクセント／ぼかした大きな影／角丸 16px 以上のカードを並べる／全部中央揃え／意味のないアイコン付き3カラム特徴カード／「✨」「🚀」／英語の見出しをそのまま大きく置く／Lorem ipsum／存在しない数字や実績。詳しくは principles.md の「AIっぽさの排除」。

## 外部ライブラリ

- 原則なしで組む（グラフも CSS の帯・横棒・SVG のスパークラインで足りる）
- 必要なら React/Next.js プロジェクトでも同じトークンを CSS 変数として置き、Tailwind の任意値ではなく変数を参照する
- フォントは Noto Sans JP（Google Fonts）＋システムフォントのフォールバック。数字に Roboto Mono を使ってもよい
